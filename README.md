# LangGraph Reflexion & Reflection Agents

A modular Python framework implementing **Reflection** and **Reflexion** agent architectures using **LangGraph**, **LangChain**, and **Google Gemini models**.

This project demonstrates iterative self-correction loops for complex text generation and automated web-research agent workflows.

---

## 🏗️ Architecture Overview

The repository contains two distinct agent patterns within the same branch:

1. **Reflection Agent (`main.py`)**: A closed dual-node feedback loop (`generate` ↔ `reflect`) that iteratively refines content (e.g., Twitter/X post optimization) based on critique without external tools.
 > Reflection Agent
(Start) ──> Generate ──> Should Continue? ──> Reflect ──> Generate ──> (End)

2. **Reflexion Agent (`reflex_main.py`)**: An extended agent loop (`draft` → `execute_tools` → `revise`) that combines internal self-critique with external web search tools (Tavily) to ground responses with factual data and citations.
  > Reflexion Agent 
(Start) ──> Draft ──> Execute Tools (Tavily Search) ──> Revise ──> Should Continue? ──> (End)

## ⚡ Technical Highlights

1. **State Management**: Built on LangGraph StateGraph using Annotated[list[BaseMessage], add_messages] to manage message histories seamlessly across loop iterations.

2. **Structured Output Parsing**: Enforces JSON schema compliance via PydanticToolsParser using custom AnswerQuestion and ReviseAnswer models for reflection and search query generation.

3. **Tool-Augmented Research**: Integrates TavilySearch via ToolNode to execute batch queries dynamically generated by the reflection phase.

4. **Turn Sanitization**: Implements message sequence cleansing to enforce alternating user (HumanMessage) and model (AIMessage) turns required by Gemini API bindings.

5. **Rate-Limit Guardrails**: Features built-in exponential backoff retries (max_retries) and node execution delays to maintain compliance with API rate limits.

## Implementations
### 1. Reflection Agent (main.py & chains.py)
The Reflection Agent continuously improves an initial output (e.g., social media post optimization) through a feedback loop between a generator and a reviewer node.

  #### a. Generation Prompt & Strict Tag Format
  The generator uses explicit markdown tags to separate its narrative rationale, target tweet content, and external references:
```
Python
generation_prompt = ChatPromptTemplate.from_messages(
    [
        (
            "system",
            "You are a tech-focused Twitter (X) influencer assistant.\n\n"
            "STRICT OUTPUT FORMAT:\n"
            "[EXPLANATION]\n<Brief rationale of changes made>\n[/EXPLANATION]\n\n"
            "[TWEET]\n<Only the revised tweet text>\n[/TWEET]\n\n"
            "[REFERENCES]\n<List URLs or handles cited. Write 'None' if none.>\n[/REFERENCES]",
        ),
        MessagesPlaceholder(variable_name="messages"),
    ]
)
```
  #### b. State Sanitization & Turn Order Enforcer
  To prevent API errors like 400 INVALID_ARGUMENT (caused by consecutive model turns or trailing AIMessage payloads), the execution flow sanitizes message turns before calling Gemini:

```Python
def reflection_node(state: GRAPH_MESSAGE):
    res = reflect_chain.invoke({"messages": state["messages"]})

    # Convert AI critique to HumanMessage to guarantee strict turn alternation
    feedback = (
        f"CRITIQUE OF PREVIOUS DRAFT:\n{res.content}\n\n"
        "Please rewrite the tweet addressing this feedback."
    )
    return {"messages": [HumanMessage(content=feedback)]}
```
### 2. Reflexion Agent (reflex_main.py, reflex_chains.py, & reflex_schemas.py)
The Reflexion Agent extends self-correction by generating dynamic research queries and executing live web searches via TavilySearch.

#### a.  Pydantic Schema Enforcement
Output structure is bound using Pydantic schemas via PydanticToolsParser to guarantee valid JSON serialization for tool calls:

```Python
class Reflection(BaseModel):
    missing: str = Field(description="Critique of missing facts or weak logic")
    superfluous: str = Field(description="Critique of unnecessary details")

class AnswerQuestion(BaseModel):
    answer: str = Field(description="250 word detailed initial answer")
    reflection: Reflection = Field(description="Internal reflection on draft")
    search_queries: list[str] = Field(description="1-3 targeted search queries")

class ReviseAnswer(AnswerQuestion):
    references: list[str] = Field(description="Citations for the updated answer")
```
#### b. Tool Node Execution (reflex_main.py)
Dynamic search execution runs through a prebuilt ToolNode:

```Python
tavily_search = TavilySearch(max_results=5)

def run_queries(search_queries: list[str], **kwargs):
    return tavily_search.batch([{"query": query} for query in search_queries])

execute_tools = ToolNode(
    [
        StructuredTool.from_function(run_queries, name=AnswerQuestion.__name__),
        StructuredTool.from_function(run_queries, name=ReviseAnswer.__name__),
    ]
)
```

## Architectural Comparison
| Feature / Dimension | Reflection Agent (`main.py`) | Reflexion Agent (`reflex_main.py`) |
| --- | --- | --- |
| **Primary Goal** | Self-correction focusing on tone, style, and general text polish. | Grounded research, factual accuracy, and citation verification. |
| **External Tools** | **None** (Closed LLM reasoning loop). | **`TavilySearch`** (Integrated via `ToolNode`). |
| **Parsing Mechanism** | Custom regex / delimiter parsing (e.g., `[EXPLANATION]`, `[TWEET]`). | Strict Pydantic Schema Parsing via `PydanticToolsParser` (`AnswerQuestion`, `ReviseAnswer`). |
| **State Output Format** | Unstructured or tag-separated string responses. | Strongly-typed objects containing explicit text, reflection metrics, search queries, and references. |
| **Graph Node Flow** | `generate` $\leftrightarrow$ `reflect` | `draft` $\rightarrow$ `execute_tools` $\rightarrow$ `revise` |
| **Context Memory** | Direct conversational history in `state["messages"]`. | Extended episodic memory combining search feedback with past critiques. |
| **Target Model** | `gemini-3.6-flash` | `gemini-3.6-flash` |

## 🚀 Getting Started
> Prerequisites: Python 3.11+
> Package Manager: uv (recommended) or pip

#### 1.  Installation
Clone the repository and install dependencies
```
git clone **repo
cd reflection-agent
uv sync
```
#### 2. Environment Setup
Create a .env file in the root directory:
```
GOOGLE_API_KEY="your-google-gemini-api-key"
TAVILY_API_KEY="your-tavily-search-api-key"  # Required for reflex_main.py
```
### 💻 Usage
#### 1. Run the Reflection Agent (Content Enhancement)
Runs a standard generation and critique cycle:
```
uv run main.py
```

#### 2. Run the Reflexion Agent (Research & Citations)
Runs the tool-augmented research loop:
```
uv run reflex_main.py
```
